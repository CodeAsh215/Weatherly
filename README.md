# 🌤️ Weatherly

A modern weather dashboard built with React, Vite and Tailwind CSS.

[Live Demo] [GitHub]

## ✨ Features

- 🔍 Search weather by city
- 🌡️ Current temperature
- 💨 Wind information
- 💧 Humidity
- 🌅 Weather details
- 🕐 Hourly forecast
- 📅 7-day forecast
- ⏳ Loading states
- ❌ Error handling
- 📱 Responsive design
- 🎨 Modern gradient UI

## 🛠️ Tech Stack

- React
- Vite
- Tailwind CSS
- JavaScript
- Lucide React
- Weather API
